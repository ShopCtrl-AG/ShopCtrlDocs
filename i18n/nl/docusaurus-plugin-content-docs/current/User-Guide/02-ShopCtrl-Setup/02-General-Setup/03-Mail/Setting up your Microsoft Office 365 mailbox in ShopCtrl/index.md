# Uw Microsoft Office 365-mailbox instellen in ShopCtrl

Er zijn twee manieren om ShopCtrl te koppelen aan uw Microsoft Office 365-mailbox:

- [via de protocollen POP3/IMAP en SMTP](./setting-up-email-protocols-to-your-microsoft-office-365-mailbox-in-shopctrl.md)
- [via de Microsoft Graph API](./setting-up-graph-api-connection-for-your-microsoft-office-365-mailbox-in-shopctrl.md)

Beide manieren zijn gebaseerd op de veilige autorisatieprocessen van het OAuth2-protocol, met de volgende voordelen:

- rechten die kunnen worden gedelegeerd
- toestemming van de gebruiker is vereist
- tokens zijn eenvoudig in te trekken

Overweeg bij uw keuze om uw mailbox te koppelen via de [Microsoft Graph API](./setting-up-graph-api-connection-for-your-microsoft-office-365-mailbox-in-shopctrl.md): de modernste, veiligste, efficiëntste en betrouwbaarste manier, die Microsoft aanbeveelt.

Om een Microsoft Office 365-mailbox in ShopCtrl te gebruiken, maakt u een apart e-mailaccount aan voor een shop of verkoopkanaal. Zie [Microsoft 365 admin center help - Add users](https://docs.microsoft.com/en-us/microsoft-365/admin/add-users/add-users) voor meer informatie.
