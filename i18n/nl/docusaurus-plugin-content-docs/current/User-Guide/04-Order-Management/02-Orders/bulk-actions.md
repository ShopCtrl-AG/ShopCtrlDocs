# Bulkacties

Met de bulkfunctie van ShopCtrl voert u verschillende acties in één keer uit op uw selectie orders.

Selecteer of [filter](./orders-introduction.md#filtering-orders) eerst een reeks orders.

U kunt nu een van de volgende bulkacties uitvoeren:

* Facturen aanmaken
* Een bepaald e-mailsjabloon versturen
* Een (aangepaste) orderstatus bijwerken
* Documenten bij de order versturen
* Exporteren naar Excel / CSV
<img src={require("/img/bulk_export_excel.png").default} height="" width="" />

* Fulfilment: orders toewijzen / toewijzing ongedaan maken

:::info[Let op:]

Het is momenteel niet mogelijk om labels of zendingen in bulk aan te maken. Deze functie staat op onze ontwikkelplanning.

:::
