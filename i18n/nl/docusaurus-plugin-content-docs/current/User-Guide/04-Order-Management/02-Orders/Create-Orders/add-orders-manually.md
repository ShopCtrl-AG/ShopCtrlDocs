# Orders handmatig toevoegen

U kunt in ShopCtrl handmatig orders aanmaken. Dat is handig voor telefonische orders of groothandelsorders die u ontvangt.
Soms wordt deze functie ook gebruikt om nieuwe artikelen aan een bestaande order toe te voegen.

1. Klik op de knop ‘Add’ in het [ordervenster](User-Guide/04-Order-Management/02-Orders/orders-introduction.md)
<img src={require("/img/order-data.png").default} height="" width="800" />
2. Selecteer voor welke shop u de order wilt toevoegen
<img src={require("/img/add-orders-manually-150x150.png").default} height="" width="" />


3. Er verschijnt een leeg [scherm met orderdetails](User-Guide/04-Order-Management/02-Orders/order-details.md), waarin u de gegevens van de order kunt gaan invullen:
<img src={require("/img/empty_order.png").default} height="" width="800" />


4. U kunt nu klantgegevens, orderregels en aanvullende ordergegevens toevoegen.
5. Klik op ‘save’ om de order af te ronden.
