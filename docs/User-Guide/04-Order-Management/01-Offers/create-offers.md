# Create Offers


You can create an offer from the **Sales > Offers** page or from within a  **Customer details page > Offers** pane.
<img src={require("/img/create-new-offer.png").default} height="" width="800" />

## Create offer
How to create an offer:
1. Go to  **Sales > Offers**.
2. Click **Add** and select a shop on which behalf you would like to issue an offer.
3. On a new offer page click **Select**
4. On the popup window search for a designated **Customer** and double-click on the name to add him/her to the offer.
5. (Alternatively) Click **Add** to create a new customer.
6. On the products pane click **Add** 
    1. Search and select **product**.
    2. Change **quantity** if needed.
    3. Click <img src={require("/img/plus-sign.png").default}  /> button to add **discount** to offer row.
7. (Optional) Change **Payment type** if it differs from the default used on the shop.
8. Select **Carrier** to ship the order.
9. Add **Shipping costs**.
10. (Optional) Choose a **Lead source**.
11. Assign a **Handling employee** by clicking the '-' sign and selecting an employee from the list. 
:::info

If handling an employee is not set manually, the employee who created the offer will be assigned on save.

:::
8. Change the **Valid until** date if needed. By default, it is set to 14 calendar days.
9. (Optional) Change the default document template by selecting a different one in the **Template** drop-down list.
10. **Save** or **Save and Close**.

### Generate document and email to customer

The offer document is autogenerated each time an offer is saved. If there were changes made to the offer, the **Mail customer** and **Mail supplier** buttons are disabled. Save the order after each edit, to apply changes to the offer and offer document.
Click the **Preview PDF** button to open autogenerated offer pdf in a new window. The offer document itself could be found in Topic menu > Attachments.

To email an offer to a customer:

1. On the offer details tab click **Mail customer** and select a template. The default mail templates in the list will match the customer culture.
2. (Alternatively) Change template to a different one:
    1.    Click **Mail Customer**.
    2.    Search for a template.
    3.    Or click an arrow next to culture and select needed culture. The list of templates will update accordingly.
    4.    Click the template to select it for auto-generating email
<img src={require("/img/offer-select-template.png").default} height="" width="" />
3. New auto-generated based on the selected template draft email will be opened on a new tab. The offer document will be enclosed as well.
4. Edit the email if needed.
5. Click **Send** when ready.

The email sent will be added both to the customer and offer conversation history.
