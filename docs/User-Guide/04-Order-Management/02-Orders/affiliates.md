# Affiliates

You can maintain statistics of the total amount of orders brought to you by different affiliates.

To enable this option, first create the affiliates Configuration > Affiliates.

<img src={require("/img/Affiliates-overview.png").default} height="" width="600" />

Configure your order synchronization to pass the id of the affiliate with each order. 
While creating an order manually, add the affiliate on the order details page.

<img src={require("/img/order-details-affilate.png").default} height="" width="600" />

You can now run a report from Reporting > Affiliate Orders to check the total sum of orders each affiliate brought you within a chosen period. 

<img src={require("/img/report-affilates-orders.png").default} height="" width="600" />
