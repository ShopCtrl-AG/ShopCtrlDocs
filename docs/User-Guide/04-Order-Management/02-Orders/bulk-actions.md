# Bulk Actions

Using the ShopCtrl bulk feature, you can apply several decisive actions to your order selection.

First select or [filter](./orders-introduction.md#filtering-orders) a range of orders.

Now you can perform one of the following bulk actions:

* Create invoices
* Send a specific email template
* Update a (custom) order status
* Send order related documents
* Export to Excel / CSV
<img src={require("/img/bulk_export_excel.png").default} height="" width="" />

* Fulfillment: allocate / de-allocate orders

:::info[Please note:]

At the moment, it is not possible to create labels or shipments in bulk. This feature is on our development roadmap.

:::
