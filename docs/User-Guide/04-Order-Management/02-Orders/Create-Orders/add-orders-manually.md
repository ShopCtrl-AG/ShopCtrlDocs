# Add Orders Manually

You can create orders manually in ShopCtrl, this is useful for phone or wholesale orders you receive.
Sometimes this function is also used to add new items to an existing order.

1. Click on the ‘Add’ button in the [order window](User-Guide/04-Order-Management/02-Orders/orders-introduction.md) 
<img src={require("/img/order-data.png").default} height="" width="800" />
2. Select for which shop you want to add the order 
<img src={require("/img/add-orders-manually-150x150.png").default} height="" width="" />


3. An empty [order details screen](User-Guide/04-Order-Management/02-Orders/order-details.md) appears, and you can now start defining the details of the order:
<img src={require("/img/empty_order.png").default} height="" width="800" />


4. Now you can start adding customer details, order rows and additional order details.
5. Click on ‘save’ to finalize the order.
