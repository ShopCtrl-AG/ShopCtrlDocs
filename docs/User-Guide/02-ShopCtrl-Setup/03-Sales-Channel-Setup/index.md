# Sales Channel Setup

A sales channel is a method, or avenue, through which you generate sales orders, for example, using a website, Amazon or eBay.

You can personalize each sales channel within ShopCtrl: for example, a trading name, logo or icon.
This enables you to operate unlimited number of sales channels.

For each channel it's possible to define:

- Company information
- Company financial information (for use on templates)
- Default templates for documents and emails
- VAT Rates
- Invoice/Document numbering format
- Communication channels
- Etc.

The branding applied to documents and communications used can be configured per sales channel.
When importing orders from a certain sales channel, all relevant branding will be applied; documents use the correct logo and layout, display your correct company address, and emails will come from your configured sales channel email address.
