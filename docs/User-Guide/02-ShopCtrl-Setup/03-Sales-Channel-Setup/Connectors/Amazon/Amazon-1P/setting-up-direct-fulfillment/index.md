# Setting up Direct Fulfillment

:::info[**Required Permissions**]

An employee must be assigned to the shop with a **Shop Owner Admin** role to perform actions referred to in this article.

:::

Amazon 1P Direct Fulfillment (also known as Vendor Direct Fulfillment or VDF) allows vendors to ship purchase orders directly to end customers on behalf of Amazon, rather than shipping inventory to Amazon fulfillment centers. This is commonly referred to as a dropship model.

## Direct Fulfillment Module Features

With the Amazon 1P Direct Fulfillment module you can:

- Import dropship purchase orders from Amazon Vendor Central
- Accept or reject purchase orders back to Amazon
- Request shipping labels from Amazon via the VDF Carrier
- Submit shipment confirmations to Amazon after dispatch
- Export inventory availability updates to Amazon
- Track the full order lifecycle: New → Accepted → Shipped / Cancelled

## Key Differences from Amazon 1P

| Aspect | Amazon 1P | Direct Fulfillment (VDF) |
|---|---|---|
| Ships to | Amazon fulfillment center | End customer |
| Purchase type | Bulk buy / Weekly | Dropship |
| Order acknowledgement | Auto or manual, partial possible via pick | All-or-nothing (Accept or Reject) |
| Shipping labels | Generated by carrier integration | Requested from Amazon API |
| Shipment notification | ASN via group shipment | Shipment confirmation per shipment |
| Bulk buy offers | Supported | Not applicable |

## Configuration Guide

To set up the integration, you need to complete these two configuration steps:

1. **[Amazon Profile Configuration](../setting-up-integration-with-amazon-1p/amazon-1p-profile-configuration.md)**: Create the application and generate credentials for your store, granting ShopCtrl access to your open API. Follow the same steps as for the standard Amazon 1P integration.
2. **[Setting Up VDF Synchronization in ShopCtrl](./amazon-vdf-setting-up-shopctrl-synchronization.md)**: Configure the carrier account, API connection, and synchronization rules for Direct Fulfillment orders.
