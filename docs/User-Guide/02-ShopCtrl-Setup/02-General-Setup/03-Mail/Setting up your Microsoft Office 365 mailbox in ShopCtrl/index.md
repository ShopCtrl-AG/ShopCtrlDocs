# Setting up your Microsoft Office 365 mailbox in ShopCtrl

There are two options of how ShopCtrl could be integrated with your Microsoft Office 365 mailbox:

- [using POP3/IMAP and SMTP protocols](./setting-up-email-protocols-to-your-microsoft-office-365-mailbox-in-shopctrl.md)
- [using Microsoft Graph API](./setting-up-graph-api-connection-for-your-microsoft-office-365-mailbox-in-shopctrl.md)

Both approaches are based on secure authorization flows of the OAuth2 protocol providing the following advantages:

- delegable permissions
- user consent requirement
- simple token revocation

When making a choice, consider integrating your mailbox by means of [Microsoft Graph API](./setting-up-graph-api-connection-for-your-microsoft-office-365-mailbox-in-shopctrl.md) - the most modern, secure, efficient and reliable approach recommended by Microsoft.

To start using Microsoft Office 365 mailbox in ShopCtrl, create a dedicated email account for a shop/sales channel. Check out [Microsoft 365 admin center help - Add users](https://docs.microsoft.com/en-us/microsoft-365/admin/add-users/add-users) for more information.
